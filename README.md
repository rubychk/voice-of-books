# Voice of Books

A listen-and-read app for EPUB and PDF books, for R&J's own use.

- Opens from the iPhone home screen and works without a connection.
- Imported audiobook MP3s keep playing with the screen off, with lock-screen controls.
- Books, audiobooks and reading progress sync through the signed-in user's own Google Drive.
- Only allowed Google accounts can sign in. Each account's books stay in its own Drive.

This repository holds only the app's code. No books or audio are stored here.
